# GIZLET

โปรแกรมทำ **สโลว์โมชัน** และ **เพิ่มเฟรมเรต** ให้วิดีโอ บน Windows — ใช้ RIFE คำนวณเฟรมที่อยู่ระหว่างเฟรมเดิม
(ไม่ใช่การซ้ำเฟรม) แล้วเข้ารหัสด้วย FFmpeg

**ที่เก็บนี้มีไว้แจกไฟล์ให้โหลดเท่านั้น — ไม่มีโค้ดของโปรแกรมอยู่ที่นี่**

## ดาวน์โหลด

ไปที่ **[Releases](../../releases/latest)** แล้วโหลดไฟล์ `GIZLET-<รุ่น>-portable.exe`

ไฟล์นี้เป็นแบบ**พกพา** เปิดได้เลย ไม่ต้องติดตั้ง และไม่ต้องโหลดอะไรเพิ่ม (เครื่องมือที่ใช้ทำงานอยู่ในไฟล์แล้ว)

## วิธีใช้

1. โหลดไฟล์ `.exe` แล้วเปิด (ครั้งแรก Windows อาจขึ้น *"Windows protected your PC"* → **More info → Run anyway**
   เพราะไฟล์ไม่ได้เซ็นชื่อ)
2. ลากไฟล์วิดีโอมาวางในหน้าต่างโปรแกรม หรือกด Import
3. เลือกโหมด (สโลว์ / เพิ่มเฟรมเรต) · ความเร็ว · รูปแบบไฟล์ แล้วกดเริ่มงาน

ที่เก็บไฟล์ (ตัวโปรแกรมสร้างให้เอง):

- **ผลลัพธ์** → โฟลเดอร์ `output` **ข้างไฟล์ `.exe`** (เปลี่ยนได้ในช่อง "ที่เก็บไฟล์ผลลัพธ์")
- **ไฟล์ทำงานชั่วคราว** → `%LOCALAPPDATA%\GIZLET\tmp` (ลบได้ตลอด)

## สิ่งที่ต้องมี

- Windows 10/11 แบบ 64-bit
- **การ์ดจอที่รองรับ Vulkan** (RIFE ใช้การ์ดจอคำนวณเฟรม) — เปิดแล้วถ้าบอกว่าการ์ดจอไม่พร้อม
  ให้เลือกค่ายการ์ดจอใน "ตัวเลือกขั้นสูง"

## รูปแบบไฟล์ที่ export ได้

MP4 (H.264 / H.265) · ProRes 422 · ProRes 422 HQ · ProRes 4444 · ลำดับภาพ PNG · โหมด 16-bit
